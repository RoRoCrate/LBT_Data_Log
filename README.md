# TRPG 記録管理室

ブラウザ上でTRPGキャラクターの記録を管理する静的Webアプリです。HTML/CSS/JavaScriptで動作し、データはブラウザの `localStorage` に保存されます。

## 起動方法

1. ZIPを展開します。
2. `index.html` をChrome、Edgeなどで開きます。
3. データ移行の前後や大きな変更の前には、「データ管理」から復元コードまたはJSONバックアップを作成してください。

## 主な機能

- **受付**：LP・欠片、MAX作成条件、最近のシナリオ履歴。シナリオ履歴は縦一列表示です。
- **シナリオ記録**：通過日、LP・欠片の増減、アイテム・備考。
- **資産・アイテム**：LP・欠片の残高、所持アイテム。
- **同期人格**：折り畳み式の一列表示。HP / SAN / 速度、所属、RANK、担当者、耐性、サポートパッシブ、戦術、分岐、固有、CT、使用回数。
- **解析E.G.O**：折り畳み式の一列表示。名称、ランク、担当者、パッシブ、覚醒・浸食、固有、メモ、持ち込み・使用回数、共有リンク。
- **人格**：分類（通常／特異／同期）、名称、身体強化。身体強化が空欄の場合は表示しません。追加順・分類順で並び替え可能。
- **E.G.O**：ランク（ZAYIN / TETH / HE / WAW / ALEPH）管理。ランク順・追加順で並び替え可能。
- **サポートパッシブ**：「通常」「死亡時」の分類。分類順・追加順で並び替え可能。
- **精神**：名称のみ。
- **データ管理**：復元コード、JSONバックアップ、初期化。

## 同期人格・解析E.G.OのMAX作成

- 同期人格は累計3回使用するとMAX作成条件を満たします。
- 解析E.G.Oは持ち込み3回と使用1回の両方を満たすとMAX作成条件を満たします。
- 条件を満たすと「MAXを作成」ボタンが表示されます。押すと元データをコピーした独立レコードが作られます。
- 同期人格のコピーはランクが `MAX-0` / `MAX-00` / `MAX-000` に変わります。解析E.G.OのコピーにはMAX識別が付きます。
- 通常性能・MAX性能の独立した記入欄はありません。コピーされたデータは元データとは独立して編集できます。

## 戦術の分岐

- 通常戦術は戦術0、戦術1、戦術2……のように追加します。
- 戦術0の分岐は戦術0-1、戦術0-2……となります。
- 分岐先は通常戦術と同じ一覧階層に表示され、分岐先からさらに分岐することはできません。

## 初期化

「データ管理」→「全データを初期化」を押し、確認ダイアログで実行します。このアプリの保存データが消去され、空の初期状態に戻ります。元に戻せないため、必要なら先にバックアップしてください。

## データ移行

### 復元コード
1. 移行元で「復元コードを生成」を選び、選択中のキャラクターまたは全キャラクターをコード化します。
2. コードをコピーし、移行先で「復元コードを読み込む」に貼り付けます。
3. 追加または置き換えを選択します。

### JSONバックアップ
「JSONを書き出す」でファイルを保存し、移行先で読み込みます。読み込みは現在のデータを置き換えるため、先にバックアップしてください。

## 注意事項

- ブラウザのデータ削除や別ブラウザへの変更で、保存データが消えることがあります。
- 共有リンクには解析E.G.Oの記録内容が含まれます。公開したくない情報を入れないでください。
- シナリオ記録を編集・削除しても、過去の増減を使った残高は自動再計算されません。


## サイトアイコン・メタタグ設定

- `images/naname-r.png` がヘッダーのナナメのR画像です。差し替える場合は同じファイル名で上書きしてください。
- `images/favicon-16.png` / `images/favicon-32.png` / `images/favicon.png` はファビコンとホーム画面用アイコンです。別画像にする場合はこれらも更新してください。
- 「データ管理」→「サイト情報・メタタグ」から、タイトル、description、keywords、author、robots、ブラウザテーマ色、OGPタイトル・説明・画像、Twitter/Xカードを入力できます。設定はそのブラウザのlocalStorageに保存されます。
- 注意：ブラウザ内で設定したメタタグは、その端末の表示に反映されるだけです。公開サイトの検索エンジンやSNSに反映するには、`index.html` のmetaタグを同じ値に編集して再公開してください。OGP画像は公開URLからアクセス可能な画像を指定してください。

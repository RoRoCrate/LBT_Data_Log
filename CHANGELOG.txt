TRPG 記録管理室 更新内容

- 初期化処理を修正。確認後にアプリ保存データを消去し、空の初期状態へ戻す
- ARCHIVE MENUを画面左上のボタンで表示・非表示に切り替え可能に
- 同期人格・解析E.G.Oを折り畳み式の縦一列表示に変更
- 人格・E.G.O・サポートパッシブ・精神を縦一列表示に統一
- E.G.Oをランク順／追加順、人格を追加順／分類順、サポートパッシブを分類順／追加順にソート可能に
- 身体強化が未記入の人格では身体強化欄を表示しない
- ホーム画面のシナリオ履歴を縦一列表示に変更
- 通常性能・MAX性能の記入欄を廃止し、条件達成後に「MAXを作成」ボタンを表示
- MAX作成ボタンで選択データの独立コピーを作成。同期人格はランクをMAX-0 / MAX-00 / MAX-000に変更
- 戦術分岐を2階層に制限。分岐先は戦術0-1、戦術0-2の形式で通常戦術と同じ一覧階層に表示
- 古い保存データにあった通常性能／MAX性能の値は画面・保存データから除去
- 入力欄は任意入力のまま維持

- サポートパッシブのソートを「追加順」「通常を先頭」「死亡時を先頭」の3種類に拡張
- 同期人格・解析E.G.Oの編集・保存後も、開いていた折りたたみ項目の状態を維持
- ヘッダーのRアイコンを提供画像に差し替え、ファビコンとApple touch iconを追加
- データ管理にサイトメタタグ設定を追加（title / description / keywords / author / robots / theme-color / OGP / Twitter card）
